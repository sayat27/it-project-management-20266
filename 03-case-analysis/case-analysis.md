# Анализ требований IT-проекта

## 1. Проект

BookMind — веб-приложение для управления процессом чтения книг.

## 2. Проблема

Пользователю необходимо удобное средство для хранения списка книг,
отслеживания прогресса чтения и сохранения заметок.

## 3. Цель

Создать веб-приложение, которое позволяет пользователю:

- управлять личной библиотекой;
- отслеживать прогресс чтения;
- создавать заметки;
- просматривать статистику.

## 4. Заинтересованные стороны

| Stakeholder | Интерес |
|---|---|
| Пользователь | Удобное управление чтением |
| Заказчик | Получение готового продукта |
| Project Manager | Соблюдение сроков и требований |
| Developer | Реализация функциональности |
| QA Engineer | Проверка качества системы |

## 5. Основные требования

### Функциональные

1. Регистрация пользователя.
2. Авторизация.
3. Добавление книги.
4. Редактирование книги.
5. Удаление книги.
6. Отслеживание прогресса.
7. Добавление заметок.
8. Просмотр статистики.
9. Поиск книг.

### Нефункциональные

1. Безопасность пользовательских данных.
2. Удобство интерфейса.
3. Быстрая загрузка страниц.
4. Совместимость с современными браузерами.
5. Надежность хранения данных.

## 6. Ограничения

- Ограниченный срок разработки.
- Ограниченное количество участников команды.
- Использование заданного технологического стека.
- Необходимость тестирования перед релизом.

## 7. Риски

| Риск | Вероятность | Влияние | Меры |
|---|---|---|---|
| Изменение требований | Средняя | Высокое | Использовать Change Request |
| Задержка разработки | Средняя | Высокое | Контроль задач |
| Технические ошибки | Средняя | Среднее | Code Review и Testing |
| Потеря данных | Низкая | Высокое | Резервное копирование |
