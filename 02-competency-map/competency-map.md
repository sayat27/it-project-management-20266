# Карта компетенций IT Project Manager

## 1. Основные компетенции

| Компетенция | Описание | Важность |
|---|---|---|
| Управление требованиями | Сбор, анализ и документирование требований проекта | Высокая |
| Планирование проекта | Определение задач, сроков и этапов проекта | Высокая |
| Управление рисками | Выявление и анализ возможных рисков | Высокая |
| Управление командой | Распределение задач и координация участников проекта | Высокая |
| Коммуникация | Взаимодействие с заказчиком и командой | Высокая |
| Agile / Scrum | Организация гибкой разработки проекта | Высокая |
| Контроль проекта | Отслеживание сроков, задач и результатов | Высокая |
| Документирование | Подготовка и ведение проектной документации | Средняя |
| Работа с инструментами | Использование GitHub, Jira, Trello и других систем | Средняя |

## 2. Технические компетенции

IT Project Manager должен понимать:

- основы программной разработки;
- жизненный цикл программного обеспечения;
- базы данных;
- API;
- системы контроля версий;
- основы тестирования;
- основы информационной безопасности.

## 3. Управленческие компетенции

Необходимы навыки:

- планирования;
- постановки задач;
- распределения ответственности;
- управления сроками;
- управления рисками;
- контроля выполнения;
- проведения встреч;
- подготовки отчетности.

## 4. Soft Skills

Важными навыками являются:

- коммуникация;
- лидерство;
- критическое мышление;
- решение проблем;
- управление конфликтами;
- работа в команде;
- тайм-менеджмент.

## 5. Инструменты

Для управления IT-проектами могут использоваться:

- GitHub;
- GitHub Projects;
- Jira;
- Trello;
- Confluence;
- Microsoft Project;
- Notion.
